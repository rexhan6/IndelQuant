一、项目概述
============

基于 AdapterRemoval v3 + CRISPResso2 的 CRISPR 基因编辑效率分析 GUI 工具。
目标：将命令行工具封装为图形界面，降低使用门槛。


二、技术栈
==========

- Python 3.10.20 (crispranalysis conda 环境)
- GUI: customtkinter 5.2.2 (基于 tkinter，现代外观)
- 拖拽: windnd 1.0.7 (Windows 文件拖拽)
- 图表: matplotlib 3.10.9
- 数据: numpy 1.24.0, pandas 3.0.2
- 打包: PyInstaller 6.20.0

外部工具：
- AdapterRemoval v3.0.0 (barcode 拆分)
- CRISPResso2 v2.3.4 (基因编辑效率分析)
- fastp (reads 修剪，Python 模拟实现)

四、核心工作流程
================

1. AdapterRemoval 流程：
   Step 1: 正向拆分 - R1/R2 -> fwd.*.r1.fastq, fwd.*.r2.fastq
   Step 2: 反向拆分 - unidentified -> rev.*.r1.fastq, rev.*.r2.fastq
   Step 3: 合并正反向 - cat rev -> fwd
   Step 4: 清理临时文件

   关键参数：
   --in-file1, --in-file2: 输入文件
   --barcode-table: Barcode 表
   --out-prefix: 输出前缀
   --demultiplex-only: 仅拆分模式
   --out-format fastq: 输出格式

2. CRISPResso2 流程：
   - 输入：合并后的 FASTQ 文件、Amplicon 序列、sgRNA 序列
   - 内部使用 fastp 进行修剪和合并
   - 输出：编辑效率量化结果

   关键参数：
   -r1: R1 文件（单端模式）
   -a: Amplicon 序列
   -g: sgRNA 序列
   -o: 输出目录
   -n: 样本名称
   -wc: 定量窗口中心（Cas9=-3）
   -w: 定量窗口大小
   -p: 进程数
   --ignore_substitutions: 忽略替换
   --plot_histogram_outliers: 直方图排除离群值


五、遇到的问题与解决方案
========================

1. 【numpy 兼容性问题】
   问题：CRISPResso2 的 C 扩展与 numpy 2.x 不兼容
   错误：Buffer dtype mismatch, expected 'DTYPE_LONG' but got 'long long'
   解决：替换 C 扩展为纯 Python 实现
   文件：CRISPResso2Align.py, CRISPRessoCOREResources.py

2. 【fastp 问题】
   问题：fastp 没有 Windows 版本
   解决：创建 Python 模拟实现
   文件：Scripts/fastp.py + fastp.bat

3. 【Tcl/Tk 版本冲突】
   问题：EXE 打包后运行报错 init.tcl 版本不匹配
   解决：修改 init.tcl 版本要求，或包含正确的数据文件

4. 【路径空格问题】
   问题：Windows 路径包含空格时命令执行失败
   解决：为所有路径添加引号

5. 【进程终止问题】
   问题：点击停止按钮无法立即终止
   解决：三重终止机制 - terminate → kill → taskkill

6. 【中文路径编码】
   问题：拖拽中文路径时报 UTF-8 错误
   解决：尝试多种编码（utf-8, gbk, gb2312, cp936）


六、用户交互功能
================

1. 文件拖拽
   - 使用 windnd 库实现
   - 支持 R1/R2/Barcode 输入框
   - 自动识别中文路径编码

2. 参数联动
   - 选择编辑工具后自动更新定量窗口参数
   - Cas9: center=-3, size=1
   - Cpf1: center=+1, size=1
   - Base editors: center=-10, size=10
   - Prime editors: center=-3, size=1

3. 样本管理
   - 自动识别拆分后的样本
   - 支持全选/全不选
   - 实时显示处理状态
   - 完成后显示结果

4. 历史记录
   - 自动保存用户输入的参数
   - 下次启动自动填入
   - 保存在 config.json 的 history 字段

5. 可视化
   - 柱状图：每个样本的编辑效率
   - 饼图：平均编辑率
   - 表格：样本状态和结果


七、关键代码说明
================

1. adapter_runner.py
   - run_adapterremoval(): 主流程函数
   - 支持正反向拆分、合并、清理
   - 路径引号处理解决空格问题

2. crispresso_runner.py
   - run_crispresso(): 调用 CRISPResso2

4. main_window.py

   - 后台线程执行分析
   - 样本状态实时更新

九、Barcode 文件格式
====================

TSV 文件，两列：
第一列：样本名
第二列：barcode 序列

示例：
A1	ATCACGTGC
A2	CTGATCGTA
B1	AGAGTCACT
B2	TAGAGCTAG


十、运行命令示例
================

AdapterRemoval:
adapterremoval3 \
  --in-file1 R1.fq.gz \
  --in-file2 R2.fq.gz \
  --barcode-table barcodes.txt \
  --out-prefix demux \
  --demultiplex-only \
  --out-format fastq \
  --threads 12

CRISPResso2:
CRISPResso \
  -r1 demux.A1.r1.fastq \
  -r2 demux.A1.r2.fastq \
  -a <amplicon_sequence> \
  -g <sgRNA_sequence> \
  -o ./results \
  -n A1 \
  -wc -3 -w 1 \
  -p 12 \
  --ignore_substitutions \
  --plot_histogram_outliers \
  --min_frequency_alleles_around_cut_to_plot 0.01
