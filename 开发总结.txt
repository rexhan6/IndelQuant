CRISPR Analysis GUI - 开发总结
================================

日期：2026年5月9日
作者：Rex Han
版本：0.0.1beta


一、项目概述
============

开发一个基于 Python 的 GUI 应用程序，用于 CRISPR 基因编辑效率分析。
核心工具：AdapterRemoval v3 + CRISPResso2
目标用户：生物信息学研究人员


二、开发过程
============

1. 初始阶段
- 基于用户原有的 shell 脚本（demux-comb-cr.sh）理解工作流程
- 确定使用 Python + GUI 框架重写

2. GUI 框架选择
- 最初使用 tkinter（内置）
- 后改用 customtkinter（更现代的外观）
- 最终尝试 PyQt5（因 Tcl/Tk 兼容性问题）

3. 核心功能实现
- AdapterRemoval：barcode 拆分、正反向合并、R1+R2 拼接
- CRISPResso2：基因编辑效率分析
- 结果解析：量化文件解析、汇总 CSV 生成

4. 问题解决
- numpy 兼容性：替换 C 扩展为纯 Python 实现
- fastp 集成：实现自定义 fastp 替代方案
- 路径空格：添加引号处理
- 进程终止：实现三重终止机制

四、优势
========

1. 用户友好
   - GUI 界面降低使用门槛
   - 参数注释帮助理解
   - 样本列表可视化管理
   - 实时进度显示

2. 功能完整
   - 覆盖 AdapterRemoval 和 CRISPResso2 主要参数
   - 支持分步运行和全部运行
   - 自动检测环境和工具
   - 结果自动汇总

3. 代码结构清晰
   - 模块化设计（core/gui/utils/config）
   - 职责分离（每个模块单一职责）
   - 详细注释便于维护

4. 跨平台潜力
   - Python 跨平台特性
   - EXE 打包便于分发


五、缺点与改进空间
==================

1. 性能问题
   - CRISPResso2 的纯 Python 对齐算法较慢
   - 大数据集处理时间长
   - 建议：考虑使用 C 扩展或调用外部工具

2. 错误处理
   - 部分错误信息不够友好
   - 进程终止有时不彻底
   - 建议：增加更详细的错误分类和处理

3. UI 响应
   - tkinter/customtkinter 在某些操作时卡顿
   - 拖拽功能受限于库支持
   - 建议：考虑使用 PyQt5 或 Web 界面

4. 依赖管理
   - 需要手动安装 AdapterRemoval 和 CRISPResso2
   - conda 环境配置复杂
   - 建议：实现自动安装和环境配置

5. 结果展示
   - 图表类型有限（仅柱状图和饼图）
   - 缺少交互式数据探索
   - 建议：集成 plotly 或 bokeh 实现交互式图表

6. 打包问题
   - Tcl/Tk 版本冲突
   - EXE 文件较大（~80MB）
   - 建议：使用 Nuitka 或优化打包配置


六、关键技术决策
================

1. 使用 subprocess 调用外部工具（而非 Python API）
   - 优点：解耦、易维护
   - 缺点：错误处理复杂

2. 使用 threading 实现后台运行
   - 优点：UI 不卡死
   - 缺点：线程间通信复杂

3. 使用 JSON 存储配置
   - 优点：简单、可读
   - 缺点：不支持复杂数据类型

4. 使用 matplotlib 绘制图表
   - 优点：功能强大、文档丰富
   - 缺点：嵌入 GUI 时有兼容性问题
