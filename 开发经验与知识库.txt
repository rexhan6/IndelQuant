3. 工作流
================================================================
Step 1: AdapterRemoval
  输入: R1/R2 FASTQ + Barcode 表
  过程: 正向barcode拆分 → 反向拆分(unidentified) → 合并正反向 → R1+R2拼接
  输出: 每个样本一个 merged.fastq 文件

Step 2: CRISPResso2
  输入: 每个样本的 merged.fastq + Amplicon序列 + sgRNA序列
  过程: 基因编辑效率分析
  输出: 每个样本一个结果目录 (CRISPResso2_样本名/)

Step 3: 结果汇总
  解析所有样本的 quantification.txt → 汇总 CSV → 图表展示

5. 关键经验教训（必读）
================================================================

【5.1 路径空格 — 最重要的一条】
  subprocess 调用外部工具时，所有路径必须用双引号包裹，用 shell=True + 字符串命令。
  绝对不能用列表参数！

  正确:
    subprocess.run(f'"{exe}" -r1 "{file}" -o "{output_dir}"', shell=True)

  错误:
    subprocess.run([exe, '-r1', file, '-o', output_dir])

  原因: Windows 用户名含空格 (C:\Users\Rex Han\...)，列表参数传给 Popen 时，
  某些工具内部解析参数会把空格后的部分截断，导致找不到文件。

  涉及文件: crispresso_runner.py, adapter_runner.py, env_checker.py, main_window.py

【5.2 CTkTextbox 没有 tag_configure 方法】
  customtkinter 的 CTkTextbox 不直接暴露 tk.Text 的 tag API。
  需要通过底层 ._textbox 访问:

    # 错误
    self.text.tag_configure(tag, foreground=color)
    self.text.insert('end', msg, tag)

    # 正确
    tb = self.text._textbox
    tb.tag_configure(tag, foreground=color)
    tb.insert('end', msg, tag)

  同理, tag_add、右键绑定、选区操作都要用 self.text._textbox。

【5.3 CRISPResso2 v2.3.0+ 需要 fastp】
  CRISPResso2 从 2.3.0 版本开始，用 fastp 替代了 FLASh 和 Trimmomatic。
  如果没装 fastp，会报 CRITICAL 错误:
    "You need to install and have the command fastp in your PATH variable"

  解决: conda install -c bioconda fastp -y

【5.4 进程终止需要三重机制】
  单纯的 terminate() 或 kill() 在 Windows 上不够彻底。
  需要三重终止:
    1. process.terminate()
    2. process.kill()
    3. subprocess.run(['taskkill', '/F', '/T', '/PID', str(pid)])

【5.5 错误信息不能截断】
  ToolError 的 reason 和 stderr 不应互斥，都要显示。
  stdout 和 stderr 都要检查（CRISPResso2 有时把错误写到 stdout）。
  还要检查 CRISPResso2 输出目录中的 CRISPResso_RUNNING_LOG.txt。

【5.6 GUI 运行状态要区分成功和失败】
  _run_done() 不能总是显示"完成 ✓"，要根据是否有失败样本显示不同状态。
  用 _has_errors 标志追踪。

【5.7 threading 后台运行】
  GUI 不能在主线程跑耗时操作，必须用 threading.Thread(daemon=True)。
  跨线程更新 UI 要用 self.root.after(0, callback)。

【5.8 配置文件原子写入】
  先写 .tmp 文件，再 os.replace() 覆盖，防止写入中断导致配置损坏。

7. 常见问题与解决方法
================================================================

Q: CRISPResso2 报错 "You need to install fastp"
A: conda install -c bioconda fastp -y

Q: "CTkTextbox object has no attribute 'tag_configure'"
A: 用 self.text._textbox.tag_configure() 代替 self.text.tag_configure()

Q: 文件找不到或参数错误（路径含空格）
A: subprocess 必须用 shell=True + 所有路径加双引号

Q: 程序运行完状态显示"完成"但实际有样本失败
A: _run_done() 要检查 _has_errors 标志

Q: 日志面板不显示颜色
A: 检查 tag 操作是否通过 self.text._textbox 访问

Q: 进程杀不掉
A: 使用三重终止机制（terminate + kill + taskkill）

Q: 配置文件损坏
A: config_manager 使用原子写入（先写 .tmp 再 os.replace）

8. 已知限制
================================================================
- customtkinter 的 CTkTextbox tag 操作依赖内部 ._textbox 属性
- 深色模式切换后，已创建的 CTkFrame/CTkLabel 不会自动刷新颜色（customtkinter 限制）
- 拖拽文件需要 tkinterdnd2 库，当前未集成
- PyInstaller 打包后 EXE 约 80MB，Tcl/Tk 版本可能冲突
- matplotlib 嵌入 customtkinter 有兼容性问题
