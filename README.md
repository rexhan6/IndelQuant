# crispranalysis shell script v1.0 beta

## function
analyse amplicon sequencing data  
identify crispr-induced mutations  
calculate modefied rate  
visualize the statistic data  

## manual
### installenv.sh
install miniconda3  
create an env  
install adapterremoval and crispresso2  

### demux-comb-cr.sh
use adapterremoval to split data
use crispresso2 to analyse the data

## based on 
adapterremoval  
crispresso2

## system requirement
anaconda3 or miniconda3  
python3  
internet access
